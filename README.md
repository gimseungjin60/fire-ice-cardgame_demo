# 재의 회랑 (Ash Corridor)

죽음조차 놓아주지 않는 자들이 되풀이해 싸우는 저주받은 회랑. 불과 서리를 엮어 마지막 심판자 앞에 서는 덱빌딩 로그라이크입니다.

**바로 플레이하기 → [데모 링크](여기에 GitHub Pages 주소가 들어갑니다)**

## 소개

- 슬레이 더 스파이어류 카드 덱빌딩 로그라이크
- 3종 캐릭터(잿불 처형자 / 서리 사냥꾼 / 재의 심판자), 각기 다른 시작 특전과 덱
- 불(점화) · 서리(동상) 두 속성의 시너지 — 열충격
- 7종 적 + 보스, 정예 전투, 야영지, 상점
- 카드를 끌어서 적에게 조준하는 드래그 인터랙션
- 캐릭터/적/장소 삽화, 배경음악 없이 효과음은 코드로 실시간 합성

## 플레이 방법

파일 하나(`index.html`)로 된 정적 웹 게임입니다. 서버나 설치 없이 **더블클릭으로 바로 실행**됩니다. 별도 빌드 과정이 없습니다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음)
- 이미지: WebP로 압축해 파일 내부에 인라인
- 사운드: Web Audio API로 실시간 합성 (외부 음원 파일 없음)

## 로컬에서 열기

이 저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone <이 저장소 주소>
cd <저장소 이름>
open index.html   # macOS
# 또는 index.html 파일을 브라우저 창에 그대로 드래그
```

## 알려진 사항

- 저장 기능 없음 — 새로고침하면 처음부터 다시 시작합니다
- 파일 용량이 큽니다(약 2MB) — 캐릭터·적·배경 삽화가 전부 파일 안에 포함되어 있어서입니다
- 개발 진행 중입니다. 피드백은 이슈로 남겨주세요.
